# discollection-web

Next.js web viewer for JSON output generated by the `discollection` CLI `organize` command.

## Features

- Upload organized JSON export and browse collection by format/sections.
- Search releases by title, artist, labels, genres, and styles.
- Switch light/dark theme.

## Development

From monorepo root:

```bash
pnpm install
pnpm --filter discollection-web dev
```

Open http://localhost:3000.

## Build And Lint

From monorepo root:

```bash
pnpm --filter discollection-web build
pnpm --filter discollection-web lint
pnpm --filter discollection-web start
```

## Input Data

Generate input JSON with CLI:

```bash
pnpm --filter discollection dev organize ./tmp/organized.json
```

Then upload `./tmp/organized.json` in the web UI.

## Deployment Notes

- Framework: Next.js
- Root Directory (Vercel): `discollection-web`
- Install command: `pnpm install --frozen-lockfile`
- Build command: `pnpm --filter discollection-web build`
